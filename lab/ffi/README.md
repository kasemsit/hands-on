# lab 64 — เรียก C library จาก Python (FFI)

แสดงว่าทำไม numpy/PyTorch ถึงเร็วทั้งที่เขียน Python — ข้างในเรียก C

```bash
make demo
```

## ไฟล์

| ไฟล์ | คืออะไร |
|------|---------|
| `fast.c` | ฟังก์ชัน C ที่คำนวณผลรวมกำลังสอง |
| `call.py` | เรียกจาก Python ด้วย `ctypes` + วัดความเร็ว + โชว์กับดัก ABI |

## สิ่งที่ได้เห็น

- C เร็วกว่า Python loop ~60 เท่าในงานนี้
- **ลืมประกาศ `restype`/`argtypes` = ได้คำตอบผิดเงียบ ๆ ไม่ crash**
